# Green Seeds

Site vitrine de Green Seeds — *Cultiver la confiance pour récolter l’excellence.*

## Publication GitHub Pages

1. Créer un dépôt public nommé `green-seeds-site`.
2. Ajouter à la racine du dépôt le contenu de cette archive : `index.html`, le dossier `assets/` et les autres fichiers présents.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
4. Enregistrer. GitHub Pages publiera le site sur l’adresse du dépôt.

Le formulaire de contact est actuellement une démonstration visuelle et devra être relié à une adresse email avant une utilisation commerciale.
